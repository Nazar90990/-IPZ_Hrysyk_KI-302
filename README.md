# Messenger Client

Навчальний клієнт-серверний месенджер для обміну текстовими повідомленнями. Проєкт містить WPF-клієнт, TCP-сервер і базу даних SQLite.

## Можливості

- Реєстрація та авторизація користувачів.
- Створення чату з зареєстрованим користувачем і пошук у списку чатів.
- Надсилання повідомлень і перегляд історії з роздільниками дат.
- Періодичне оновлення списку чатів та історії відкритого чату.
- Видалення чату після підтвердження. **Історія видаляється для обох учасників.**

## Технології та вимоги

- Windows і .NET 10 SDK.
- WPF для клієнта, консольний застосунок для сервера.
- SQLite для зберігання даних; TCP для взаємодії клієнта і сервера.
- За бажанням: Visual Studio з підтримкою розробки класичних застосунків .NET та DB Browser for SQLite для перегляду бази.

## Запуск

Відкрийте PowerShell у кореневій папці репозиторію.

1. Запустіть сервер:

   ```powershell
   dotnet run --project .\MessengerServer\MessengerServer.csproj
   ```

   Дочекайтеся повідомлення `Started on 127.0.0.1:5000` і залиште сервер запущеним.

2. В іншому вікні PowerShell запустіть клієнт:

   ```powershell
   dotnet run --project .\MessengerClient.csproj
   ```

3. Зареєструйте користувача або увійдіть у демонстраційний обліковий запис. Для початкових користувачів `nazar`, `olya`, `anna`, `max` і `denys` встановлено пароль `1234`.

У Visual Studio також можна відкрити `MessengerClient.slnx`, запустити проєкт `MessengerServer`, а потім `MessengerClient`.

## Робота з чатами

- Натисніть **«+»** та виберіть користувача, щоб створити чат.
- Виберіть чат у лівій панелі, щоб переглянути історію або надіслати повідомлення.
- Натисніть **«Видалити чат»** і підтвердьте дію, щоб видалити діалог разом із повідомленнями для обох учасників.

## База даних

Сервер автоматично створює файл `messenger_server.db` поруч зі своїми скомпільованими файлами. При типовому запуску в конфігурації Debug шлях такий:

```text
MessengerServer\bin\Debug\net10.0\messenger_server.db
```

Основні таблиці:

- `Users` — облікові записи користувачів.
- `Chats` — пари учасників діалогів.
- `Messages` — повідомлення та час їх створення.
- `SchemaMigrations` — відмітки про виконані міграції.

Час повідомлень зберігається в UTC, а в клієнті відображається за локальним часом комп’ютера. Локальний файл бази не входить до репозиторію. Для перегляду відкрийте його в DB Browser for SQLite та виберіть таблицю на вкладці **Browse Data**.

## TCP-команди

Сервер слухає `127.0.0.1:5000` і підтримує текстові команди `REGISTER`, `LOGIN`, `GET_USERS`, `GET_CHATS`, `CREATE_CHAT`, `DELETE_CHAT`, `SEND_MESSAGE`, `GET_HISTORY` і `PING`.

Ручні тестові сценарії наведено у файлі [LAB4_TESTS.md](LAB4_TESTS.md). Перед запуском тестів запустіть сервер, а потім клієнт.

## Примітка щодо безпеки

Це навчальний проєкт, не призначений для використання з реальними паролями або публічного розгортання: паролі зберігаються без хешування, а TCP-з’єднання не шифрується. Демонстраційні облікові записи призначені лише для локального тестування.
